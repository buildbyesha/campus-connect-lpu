About the Portal

What is the Campus Event Portal?

The Campus Event Management & Registration Portal is a simple website where students can see the events happening in their college and fill out a registration form.

Why is it useful?

Students do not have to search notice boards or group chats for event details. Everything is available in one place, which saves time and makes events easier to find.

Main Objectives

  • Show all college events in one place
  • Make event registration easy for students
  • Display event dates, venues and seat availability

Main Features

  • View upcoming events
  • Online registration interface
  • Event schedules
  • Seat availability display
  • Easy access to event information

Note: This project uses only HTML and CSS, so the registration and seat numbers are for display only.
